## About the Project

This portfolio is designed to present my technical background, projects, and development experience through a distinctive and interactive web experience.

The website combines a premium visual design with interactive elements, smooth navigation, and a terminal-inspired interface. It reflects my interest in frontend development, Python, AI/ML, and building practical applications with modern development tools.

## Key Features

- **Premium UI/UX:** A dark mocha-inspired theme with metallic typography and lavender accents.
- **Interactive Hero Section:** A terminal-inspired interface with a character-by-character typing effect.
- **Smooth Navigation:** Animated scrolling between portfolio sections.
- **Glass-Inspired Components:** Capsule-style buttons, reflective details, and modern visual elements.
- **Project Showcase:** Dedicated cards to present selected projects and their details.
- **Responsive Experience:** Designed for use across desktop and mobile screen sizes.
- **Live Deployment:** Hosted on Vercel and connected to a GitHub repository.

## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sanil-rgb/my-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd my-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```
